# Contributing

Thanks for helping make Guildcraft more useful.

## Local setup

No package install is required. Serve the repository root with any static server and open it in a modern browser.

## Product principles

- Keep the tool useful without accounts, trackers, or network requests.
- Prefer deterministic guidance over opaque “AI” output.
- Keep the least-privilege Discord permission model.
- Make playbooks broadly reusable; product-specific notes should be optional context.
- Test keyboard navigation and layouts at desktop and mobile widths.
- Keep exported blueprint changes backward-compatible or increment `schemaVersion`.

## Pull requests

Describe the user problem, the behavior change, and how you tested it. Screenshots are useful for visible changes. Do not include credentials, Discord tokens, member data, or proprietary server exports.
